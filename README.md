# camera-motion-exp

JIN 的镜头学与运镜实验：Seedance 视频提示词里的镜头怎么写，哪些在 Seedance 里测过。本仓库同时是一个 Skill：`SKILL.md`（Skill 名 camera-motion-exp），详细内容在 `references/镜头学.md`。

内容：镜头切分、POV 与镜头因果、画面与对白对应、机位视场运镜、景别／角度／运镜／镜头密度词表（每张表后附 Seedance 里的实测）、一镜到底的排法〔候选〕、待补（构图学、灯光、节奏）。
