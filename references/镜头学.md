## 零、底层逻辑与核心逻辑〔JIN 2026-10-24 提出；候选，没有单独对照〕

零.一管每句镜头话怎么写；零.二管写之前怎么决定。

### 零.一 底层逻辑：每句镜头话回答四件事，最后加三句保险

镜头的句子不是给镜头起名字（推、拉、跟），而是告诉模型这个镜头怎么走完这一段。每一段回答四件事：

1. **从哪里开始：**第一帧的机位和画面里有什么（核心第 4 条；§四.4）。
2. **跟着谁、什么让它动：**围绕谁；是角色在动、摄影机在动，还是 POV 的身体在动（§四.1）。手机 POV 里每次变化都要写原因，否则镜头不会动（§二.3）。
3. **沿什么路线走：**往哪个方向、走多快、有没有转向；写路径，不写设备名（§六.4）。
4. **最后停在哪里：**落幅是什么画面、镜头在哪里停住。只写"不断推进"等于没有终点，它可能一直推〔博主，参考〕（§五"推"）；一镜到底的结尾写"镜头停止移动，定格在……"（§六.6）。

这一节只是总纲，细则在别处：运镜句式见 §四.3〔官方 2.5〕；一镜到底的起幅、过程、落幅见 §六.2；手机 POV 的因果见 §二；写之前先决定什么，见零.二。

**最后的保险（只用于一镜到底或连续运镜）：**在提示词最后加三句短的：不切镜，不瞬移，不穿墙。〔JIN 提出，认为简单但防崩；博主视频里最后也强调这三句〔博主，参考〕；Seedance 里没有单独对照，不当规则。〕三句管的是镜头因果：镜头不跳到别处（切镜、瞬移），也不穿过实体（穿墙）。
- 只放这三句，不扩成一长串（核心第 16 条：限制只保护最脆弱的事实，"摄影机因果"在它的清单里；不堆固定的超长负面词）。
- 先把上面四件事写清楚。正面把路线写清（例如"从门口进来，沿走廊向前"）比这三句更重要，三句只是保险。
- 有意切镜的提示词不加"不切镜"（§一.1）。提示词里已经有同类的镜头保险句时，不再叠加，免得和正文重复（核心第 16 条）。

### 零.二 核心逻辑：写镜头句子之前，先决定五件事〔JIN 2026-10-24 提出；候选；拆片试填 4 条，没有按戏型做过对照〕

1. **这一段是哪类戏：**追逐、对白、情绪、打斗……词表用真人写实 R02 的"每镜主要任务"，不另立一份。
2. **镜头跟不跟：**随某个对象的运动而动；还是固定，或按自己的路线动（缓推、环绕）。
3. **跟谁：**第一个对象是谁。它就是起点（零.一的第 1 件事）。
4. **中途换不换：**换几次，靠什么交接。
5. **最后有落点，还是一直跟到结尾：**落点＝镜头最后停住的位置或构图（零.一的第 4 件事）。

**跟的对象不一定是主角：**任何能被镜头跟着的东西都行：旁观者、声音的来源、移动的物件（见 §六.3 动接）。

**换对象要写一个触发：**画外的声音、别人的视线或手势、遮挡、物体的运动、人物动作。〔博主，参考；JIN 看过成片，口述，提示词的主要节点都有对应；单次〕完整的追逐例子见 §六.7。

"哪类戏通常怎么答"现在没有足够的样本，不写。先照这五问拆片、记录，同类拆到三条再回来看。

## 一、镜头切分：镜头N 与一镜到底

1. 有切镜才写"镜头1、镜头2……"，镜头之间是硬切；每个镜头一个主要任务。〔JIN 规定 2026-10-20〕
2. 一镜到底不写镜头N，也不用"镜头一、镜头二"当小标题；用"先……，再……，然后……"一路写，每一步写清是谁或什么让画面变化。〔JIN 规定 2026-10-18、10-20〕
3. 2.0 写不写秒数都可以，求稳不写。〔JIN 规定 2026-10-20〕
4. 已知的一个反例：Chibi 的一条一镜到底成功案例（糯糯晚上出门遇雷，2.0，15 秒，2026-10-12）写过"镜头1/2/3"，并写明"下面三个镜头是同一条连续镜头里的三个阶段"，成片连续、没有切镜（单次）。按新规则不再这样写；改写后第一次生成要留意，结果记进 video-exp。

## 二、POV（第一人称视角）与镜头因果

〔JIN 规定 2026-10-12，沙堡 15 秒失败后定。糯糯出门遇雷（10-12）成功，站立版重写（10-13）生成正确，都是单次。完整原话在 JIN 的项目文档《POV 镜头与手的写法-必读》，案例全文在私有库 video-exp。〕

1. 固定层逐字复制："真实手机实拍风格，第一人称 POV 手持手机拍摄"，再接"镜头保持稳定，只随〔本片 POV 具体动作〕产生自然的人体晃动"。〔欢迎回家前空翻成功案例的写法〕
2. 手机 POV 默认一镜到底，不写"固定机位"；只有 JIN 要求切镜才写"切至镜头N"。
3. 每次景别或构图变化都写明一个原因：角色移动，或 POV 的身体移动（低头、凑近、蹲下、抬起手机、转头跟看、被撞）。没有原因，镜头就不会动。
4. 剧情本身要给 POV 身体动作。POV 只在画外说话时，也要给他身体反应（转头跟看、凑近），否则整条片镜头会卡住。交给别的写手的剧情里也要写 POV 做什么。〔沙堡卡住、机场里 POV 有动作则镜头会动；原因是推测，没有单独验证〕
5. 第一帧写镜头在哪里（高度、朝向、画面里有什么），不写拍摄者的身体姿势（"蹲着""举着""一臂远"会把手带进画面）。
6. 不写"手不入画"这类否定句，写"画面中有且仅有……"；POV 的手只在有任务时入画，写清从哪条边进入、做什么、何时离开。
7. 交付前只读镜头和 POV 句子：镜头为什么动？谁让它动？手会不会入画？

适用范围：第一人称。第三人称、固定机位的镜头不适用本节。

## 三、画面与对白对应

画面和对话对不上（说话的人不在画面里、只拍到胸口、台词赶）是镜头学问题，先查这里。

1. 说话的镜头要拍到说话的人：他的脸、他的视角，或从听者肩后看他；别只拍到胸口。〔JIN 规定 2026-10-16；来自 Ani 第 3 段〕
2. 台词句子短，语速慢，词之间留停顿，说话的镜头多留时间。〔JIN 规定 2026-10-16〕

## 四、机位、视场与运镜

1. 构图变化只有一个执行者：摄影机、角色，或 POV 的身体；每个阶段写明。〔JIN skill；官方〕
2. 一个镜头只用一种运镜，不同时推拉摇移。〔官方 2.0；2.5 未提〕
3. 运镜写成：什么运镜、围绕谁、从哪里开始、往哪里走、停在哪里。〔官方 2.5〕
4. 〔候选〕机位写成物理位置：在哪里、离地多高、离目标多远、望向哪里；过肩镜头写清前景是谁。
5. 〔候选〕视场写对角视场度数，后面接"整个镜头视场锁定"。

4、5 的老家是真人写实 Skill（R06、R08）；Ani 在 2.0 上 4 段都这样写，没有单独测过。细则回真人写实 Skill 查，这里不再抄一份。给 Chibi 用之前先试片 1–2 次。

## 五、景别、角度、运镜、镜头密度：词表

〔影像常识〕下面的表只说这些词在电影里指什么。每张表后面的"在 Seedance 里"只写 JIN 自己的生成和 video-exp 里复盘过的样本；没有写的就是没测，不当作有效。

**怎么用：** 词只是名字，写进提示词前要翻成画面：入画到哪里为止、机位的物理位置（高度、侧别、距离、瞄准）、路径（从哪里开始、往哪里走、停在哪里）。角度词怎么翻成机位，见真人写实 Skill 的 R06；命名的手法怎么翻成物理指令，见 R09；这里不再抄。〔候选〕景别的分档各家不一（传统五分法里中景是膝盖以上，下表的中景是腰以上），只写词，模型取哪一档不确定；要精确就在词后面补入画边界，例如"中景，腰部以上入画"。

### 景别（离多近）

| 词 | 画面 | 常用来 |
| --- | --- | --- |
| 大远景 | 人小如点，环境为主 | 定场、孤独、史诗 |
| 远景 | 全身可见但小，环境为主 | 人与场景的关系、方位 |
| 全景 | 全身，脚下留空 | 完整动作 |
| 中全景 | 膝盖以上 | 半身动作兼顾表情 |
| 中景 | 腰以上 | 对话、常规叙事 |
| 中近景 | 胸以上 | 表情加手势 |
| 近景 | 肩或锁骨以上 | 情绪、单人对白 |
| 特写 | 脸或五官 | 关键反应、口型、眼神 |
| 大特写 | 眼、嘴、手等局部 | 微表情、线索 |
| 插入镜头 | 与主线无直接关系的物件局部 | 线索、道具、屏幕 |

越近越强调情绪，越远越强调环境和关系。

在 Seedance 里：
- 景别词只写在镜头标题里不会换景别，要写明是谁让它变（§二.3、§四.1）。〔JIN 规定〕
- 机位不动，让人物走远走近来换景别：Rin 画外取景（15 秒），人物后移，近景变中景，提示词写明不用推拉和变焦，成片做到了。〔JIN 实测，单次〕
- 每个景别词本身对应什么画面，还没有系统测过。

### 角度（怎么看）

| 词 | 画面 | 常用来 |
| --- | --- | --- |
| 平视 | 机位与眼睛齐平 | 客观、亲近 |
| 仰角 | 从下往上拍 | 权威、压迫、显得高大 |
| 俯角 | 从上往下拍 | 渺小、弱势、审视 |
| 顶角 | 正上方垂直向下 | 几何感、群像、宿命 |
| 荷兰角 | 画面倾斜（只是滚转） | 失衡、恐惧、悬念 |
| 正面 | 面对面 | 直接、冲击 |
| 正侧 | 侧面轮廓 | 剪影、对峙 |
| 3/4 侧 | 斜约 45° | 最自然，对话默认 |
| 背面 | 背对镜头 | 神秘、跟随、留白 |
| 过肩 | 隔着前景人物的肩拍对方 | 对话空间、代入 |

在 Seedance 里：
- 台阶重逢（7 秒，另有故事板图）：背对镜头的人从左侧入画形成的过肩关系，和仰视台阶，都做到了。〔JIN 实测，单次，有故事板图〕
- 魏的治疗台扫描（15 秒）首镜写"略高并向下看"，成片偏低且倾斜。〔JIN 实测，单次〕角度词不如机位位置可靠，所以按 R06 写成物理位置。
- 顶角、荷兰角：JIN 的生成里未测。荷兰角只是滚转，不换机位侧别（R06）。

### 运镜（怎么动）

| 词 | 画面 | 常用来 |
| --- | --- | --- |
| 固定 | 机位不动 | 稳定、纪实、克制 |
| 推 | 机位走向主体 | 聚焦、揭示、内心收紧 |
| 拉 | 机位远离主体 | 揭示环境、孤独、收尾 |
| 摇 | 机位不动，左右转向 | 巡视、跟随横向运动 |
| 俯仰 | 机位不动，上下转向 | 展示高度和体量 |
| 横移 | 机位横向平移 | 跟着走、空间延展 |
| 升降 | 机位垂直升降 | 揭示规模、情绪升华 |
| 环绕 | 绕着主体转 | 全面展示、对峙、高光 |
| 跟随 | 沿主体运动方向移动 | 带观众一起走、连续感 |
| 手持 | 轻微不稳 | 纪实、紧张、主观 |
| 变焦 | 焦距变化，机位不动（光学，不是机位运动） | 快速聚焦 |
| 稳定器跟随 | 手持但很稳 | 流畅的长镜头 |
| POV | 模拟角色视线 | 代入 |

在 Seedance 里：
- 固定：手机 POV 不写（§二.2）。沙堡写了"固定机位的手持 POV"，整片镜头卡住；去掉"固定机位"的另一版也卡住，最可能的原因是 POV 没有身体动作，未单独验证。〔JIN 实测〕
- 推：写了"远处出现 → POV 向前 → 进入中景"，成片前 4–5 秒真的在往前推，占掉互动的时间（核心第 3、4 条）。〔JIN 实测，单次〕要推就写停在哪里；只写"不断向前推进"，它可能一直推。〔博主，参考〕
- 拉：JIN 自己的片未测。外部的链剑战斗样本写了"摄影机快速后退并把人物锁在近景右侧"，做到了。〔外部样本〕
- 升降、环绕、跟随：LibTV 第 6 镜（6 秒，2.5）里摄影机跟着被击飞的酒碗贴地走，穿过翻起的桌板下方并升起，再绕着背靠背的两人转（提示词写近 180°），推到女主近景；案例记录把"酒碗引导视线""旋转叠加环绕"都标为明确成功。〔JIN 实测，单次〕凉亭样本（7 秒）前约 4.9 秒摄影机跟着一组树叶下降，依次揭示山雾、亭檐、灯笼、亭柱、栏杆和坐着的人物，约 4.88 秒处是提示词写明的跳切。〔JIN 实测，单次〕Chibi Skill 收录的早期 Dreamina 10 秒样本用"角色相对路径点"写环绕跟拍，环绕做到了（同一条提示词里"走两步"和"步伐不停"互相冲突，是它自己记下的问题），写法见 §六.2。〔JIN skill〕
- 手持：用固定层原句（§二.1）。不要同时写"画面绝对稳定"或"固定机位"，两句会打架。〔博主，参考〕
- 变焦：Rin 的成功提示词明写"不使用推拉、变焦或切换"。〔JIN 实测，单次〕急变焦见真人 R10。
- 稳定器、斯坦尼康、升降机、摇臂这类设备名：Rin 的失败版写了"实体镜头""镜头底座""扶住镜头"，成片真的多出一台设备；改成只写手到哪里、哪里保持为空、画面怎么动以后正常。〔JIN 实测，失败与通过各一片，入口版本没存〕所以写运动，不写设备名。〔候选〕
- 摇、俯仰、横移：未测。

### 镜头密度（切多快）

| 类型 | 特征 | 常用来 |
| --- | --- | --- |
| 高密度 | 1–3 秒一镜 | 动作、紧张、预告片 |
| 中密度 | 3–6 秒一镜 | 常规叙事、对话 |
| 低密度 | 10 秒以上一镜 | 抒情、氛围 |
| 一镜到底 | 不切 | 沉浸、连续 |
| 静—动对比 | 慢突然转快 | 蓄力、爆发 |
| 节拍切换 | 切点对音乐或台词 | MV、预告片 |

信息多就切快，要沉淀就切慢。

在 Seedance 里：
- 手机 POV 默认一镜到底；切镜时每镜一个任务（§一）。〔JIN 规定〕
- 时长不够就少切：治疗台 7 秒版没有执行四镜流程，15 秒版执行了。〔JIN 实测，单次〕
- 每 1.5–2 秒换一次机位：成片确实出现了各种镜头，但镜与镜之间的人物位置、朝向、距离没有继承，空间反复重置。〔外部样本，JIN 定性为失败〕

## 六、一镜到底的排法〔候选〕

〔影像常识〕这套排法没有整体试片过。每条后面写 video-exp 里有没有对得上的样本。

1. **本质：** 一镜到底是把剪辑里"换景别、换角度、换节奏"的工作交给运镜和调度。景别靠推、拉、跟，或人物走近走远，连续地变；角度靠摄影机升降、绕行连续地变；节奏由镜头移动的快慢和人物入画出画的次数决定。
2. **三个锚点：** 起幅（开场构图，锁空间和机位）→ 过程（运镜和调度连续推进，每段一个主要变化，写明谁让它变）→ 落幅（收尾构图，锁最后的画面）。起幅就是第一帧（核心第 4 条）；每段一个主要变化同核心第 6、11 条。路径的写法见 Chibi 的"起始方位＋身体锚点 → 下一方位＋身体锚点 → 环绕方向 → 最终距离与景别"；起幅、落幅、停留的写法见真人 R09。
3. **隐形转场**（一镜里换空间，不切）：
   - 动接：沿同一方向运动的前景物带着镜头走，一路揭示新的空间。树叶和酒碗两例都做到了（见 §五 运镜），是目前证据最足的一种。〔JIN 实测，各单次〕
   - 借位遮挡：前景的物体或框遮满画面的一瞬间换空间。治疗台镜头 4 用吊臂遮满画面做剪辑出口，有效，但那是切镜的出口；LibTV 第 6 镜里镜头穿过翻起的桌板下方，是最接近的一镜内样本。〔JIN 实测，各单次〕一镜里穿窗框换空间：未测。
   - 焦点转移：不动机位，焦点从前景跳到后景。台阶样本里方向成立，但不够明显，没法单独认出来。〔JIN 实测，单次〕
4. **要留意：**
   - 路径里每一段都要占秒数（核心第 4 条）。已做到的：糯糯出门遇雷 3 段 15 秒；LibTV 第 6 镜 6 秒里有跟酒碗 → 穿桌下升起 → 环绕 → 推近，开头靠酒碗把镜头带进战局。未测：把七八段的长路径（航拍定场 → 下降 → 穿窗 → 跟走 → 绕到正面 → 推近 → 眼睛大特写）放进 10–15 秒；先按核心第 11 条减段，或拆开生成。
   - 从无人的航拍大远景开场，要先过核心第 4 条（人物第一帧就在场，除非 JIN 要空镜开场）和真人 R01（极端广角加细微表演、空镜开场却要动作）。
   - 写路径，不写设备名（升降机、斯坦尼康、摇臂），见 §五 运镜里的 Rin 配对。
   - 手机 POV 里摄影机就是拍摄者的手机：升降靠站起蹲下，绕行靠人绕着走；航拍和斯坦尼康式的大范围移动做不到（§二.3）。
5. **剪辑类手法**（蒙太奇、平行或交叉蒙太奇、匹配剪辑、跳切、多机位）都要切镜，写法归 §一.1。倒放、变速：未测。
6. **2.5 长一镜到底的阶段写法**（30 秒、POV 反复转头回位）：每个阶段依次写景别、镜头、主要事件、结束时，用来代替官方阶段写法里的"开始时"和"承接上一阶段"。阶段名用"开场／之后／之后（结尾）"，不写镜头N。秒数区间写不写都可以，JIN 不执着；通过的那版没写。
   - 景别：写这一阶段开头看到的画面；阶段里景别因 POV 转头而变，就写"先是……；POV 转头之后变成……"，并写清每个景别里谁入画、脸看不看得清（§三）。
   - 镜头：写机位在哪、朝向哪、什么让它动（§二.3）；不动的阶段写"不转动，景别和距离都不变，只有轻微的手持晃动"。回到之前的位置，写"回到相近的低机位全景"，不写"同一个机位和朝向"——每个"同一"都是一把要守住的锁（核心第 16 条）。
   - 最后一个阶段的结尾写"镜头停止移动，定格在……"，不写"最后两秒"。
   - 咖啡厅 30 秒（Q 版三角色，2.5，16:9）用这个写法生成，JIN 看完说能完整表达他的想法，也比以往的 2.5 稳定。成片（JIN 给 mp4 和 10 帧截图，视频和图都不入库；ffmpeg／OpenCV 实测）：一镜到底，没有切镜；六段按顺序发生；三次转头（右、左、右）起止约 9.2–11.7、18.2–20.3、24.5–27.2 秒，各约 2.2–2.8 秒，扫过约一个画面宽；停留约 9.2／6.4／4.2／2.8 秒；停着时镜头纹丝不动（背景漂移最大约 1 像素），提示词写的"轻微的手持晃动"没有出现；结尾 27.2–30 秒基本定格（不是逐帧重复）。没写秒数。JIN 看完整片：镜头、角色该做的都做了，声音没问题；节奏像纪录片、不像戏剧，见 §七（单次）。开场写"从头到脚"，截图里只见上半身（脚被桌沿挡住，Claude 看图）。同内容带秒数区间的版本没有生成过；"同一"改"相近"是平台 agent 的改法，两种写法没有单独对比。JIN 记录过一位外部作者的"每段固定模板"（每段都列镜头运动、景别等栏位），在 30 秒提示词和 15 秒 POV 喜剧上也生成成功，是同一类做法，原文不在库里（见 Chibi 的 handoff 笔记）。〔JIN 指定写法 2026-10-21；JIN 实测，各单次；案例：video-exp 的 2026-10-21-cafe-30s-pov-shot-fields-success〕
7. **追逐、搜寻类：把摄影机写成"有反应的人"**〔博主，参考；JIN 看过成片，口述；我们没生成过〕博主讲"要告诉它镜头从哪里开始"时给的一条 20 秒涩谷追逐长镜头提示词，按秒分 7 段，每段 2–4 秒。它的写法：
   - 起点是旁观者：镜头先落在街头艺人的中近景上，画外传来喊声，她抬头看去，镜头随她的视线去找人。〔和核心第 4 条有张力：第一帧是旁观者，主角约 3 秒后才入画，"找人"占了秒数；用不用由 JIN 定。〕
   - 镜头每次动都写触发源：画外的声音（喘息、刹车和喇叭、旋转门的撞击）、别人的视线和手势、遮挡（汽车从前景横插进来）。这是 §二.3"镜头要有原因"在第三人称里的样子。
   - 镜头有"人味"：迟半拍才跟上、被声音拉回、减速并左右修正、猛然甩向某人；提示词开头一段（截图只见到后半句）写明保留真实的反应延迟、甩动、过冲和跟焦修正。
   - 焦点跟着镜头在看什么走：从旁观者拉到主角脸上（先过焦一下）、锁住领头者、短暂落错路人再失焦、漂移后落到远处的人。拉焦这类命名手法怎么写成物理指令，见真人写实 Skill 的 R09。
   - 终点写成空间关系：最后一段停在"主角在前、追击者不断缩短距离"，不是静止画面。
   - 要留意：①每 2–4 秒里叠了运镜、焦点、人物动作和画外声音几条线，和核心第 11 条（一段一个主要目标）、真人写实 T4 的"手法要稀"有张力。②JIN 看过成片（口述，单次，博主展示的，可能挑选过；口述只说看得见的，没说的不等于没做）：提示词写的主要节点——旁观者起点、转向主角、汽车遮挡、找人、被声音拉向酒店门口、追击者出场、领头者指认后回到主角、结尾追击——口述里都有对应。过焦、误落路人、迟半拍这类镜头细节，以及追击者的人数、穿着，口述没提或与提示词字面不同，没核。成片里还有两句画外日语喊话，可见的提示词只写了喊声和指认的动作，没写喊的内容。
